# Changelog

All notable changes to this project will be documented here.

This project uses SemVer-style tags such as `v1.0.0`.

## Unreleased

- Added public repository documentation and release process guidance.

## v1.0.0

- Initial public baseline for Card Builder.
- Added authenticated magic-link access through Supabase.
- Added username profiles for shared build attribution.
- Added cloud-synced private builds with deletion tombstones.
- Added published shared build snapshots with read-only preview and `Save As`.
- Added equipment set presets, Upgrade 2 usability fields, PNG export, and Wendy sample preview protections.
- Added TypeScript state/sync modules, unit coverage, Playwright e2e coverage, and GitHub Actions CI/CD.
